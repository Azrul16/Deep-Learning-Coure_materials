# Deep Learning Course Materials

A small notebook-based repository for practicing deep learning workflows. It contains separate notebooks for artificial neural networks and convolutional neural networks.

## Contents

- `ANN_Codes.ipynb` - Artificial neural network practice notebook.
- `CNN_Codes.ipynb` - Convolutional neural network practice notebook.

## Tech Stack

- Python
- Jupyter Notebook
- Common deep-learning/data-science libraries such as NumPy, pandas, TensorFlow/Keras, and matplotlib depending on the notebook cells.

## Getting Started

Create an environment and install notebook tooling:

```bash
pip install notebook numpy pandas matplotlib tensorflow scikit-learn
jupyter notebook
```

Open either notebook and run the cells in order.

## Notes

This repository is intended as course-practice material rather than a packaged application. Keep datasets and trained model artifacts separate unless they are required for a specific exercise.
